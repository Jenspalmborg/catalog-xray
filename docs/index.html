What you get

What to add

Kinds of products shoppers look at alongside yours that you don’t carry, with the styles they pick and a price range.

Keywords to add

Words shoppers use for products like yours that don’t find them in your own search today.

Assortment balance

Your share of the range per product area, next to that area’s share of what shoppers buy.

Search QA

Your key searches run against your own catalog, with the weak ones flagged.

Gentle by design

  • Upload a product export no requests
  • The store’s product API a few requests
  • A product feed one request
  • Common Crawl’s public archive no requests to the store
  • A sample of product pages last resort, max 150

The lightest available route is used first. Every request follows robots.txt and identifies itself.

Run it

git clone https://github.com/Jenspalmborg/catalog-xray.git && cd catalog-xray
uv sync && cp .env.example .env   # add your UNBOXAI_API_KEY
uv run xray-web                   # paste a URL or upload an export

Runs on your machine with your own key from unboxai.com/behaviorgpt. Needs Python 3.11+ and uv. A first scan takes a few minutes.
